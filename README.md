# EKT AI — ассистент интернет-магазина

EKT AI помогает клиентам ekt.kz подобрать электротехнический товар, узнать наличие и цену, найти аналог и собрать корзину без ожидания менеджера.

## Архитектура

```text
Веб-интерфейс → POST /api/chat → FastAPI → агент → каталог EKT или демо-каталог
                                      ↓
                   корзина → ссылка на демо-корзину в Vercel
```

Фронтенд хранит историю диалога в открытой вкладке, а `session_id` и подписанное состояние корзины — в `sessionStorage`. При наличии `CART_SIGNING_KEY` сервер проверяет подпись и восстанавливает корзину при каждом запросе: это сохраняет её между экземплярами Vercel Functions. Если API недоступен, интерфейс сообщает об ошибке и не подменяет ответ вымышленными товарами или корзиной.

## Технологии

- FastAPI и Pydantic;
- OpenAI API с вызовом инструментов;
- HTML, JavaScript и Tailwind CSS CDN;
- API каталога ekt.kz или синтетический каталог при `DEMO_MODE=1`.

## Запуск

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Настройте переменные окружения:

   ```env
   OPENAI_API_KEY=...
   MODEL_NAME=gpt-4.1-mini
   DEMO_MODE=1
   ```

   Для живого каталога установите `DEMO_MODE=0`, `EKT_API_USER`, `EKT_API_PASSWORD` и при необходимости `CATALOG_PAGES`. `CORS_ORIGINS` задаёт разрешённые источники через запятую.

3. Запустите приложение:

   ```bash
   uvicorn main:app --reload
   ```

4. Откройте `http://127.0.0.1:8000`.

Живая ссылка на демо: https://ekt-ai-assistant-demo.vercel.app

### Деплой на Vercel

Из корня репозитория запустите `python scripts/deploy_vercel.py`. Скрипт запросит токен Vercel через скрытый ввод, создаст проект при необходимости, настроит для нового проекта `DEMO_MODE=1` и отдельный чувствительный `CART_SIGNING_KEY` в переменных окружения Vercel, загрузит исходники и дождётся окончания production-деплоя. Токен и ключ не записываются в файлы. Для подключения модели добавьте `OPENAI_API_KEY` как чувствительную переменную окружения Production в Vercel и выполните новый деплой. Для проверки публичного адреса запустите `python scripts/smoke_vercel.py --expect-openai`.

Для реального каталога потребуются `EKT_API_USER` и `EKT_API_PASSWORD` в переменных окружения Production и `DEMO_MODE=0`. Предоставленный API EKT позволяет читать список и детали товаров; методов изменения корзины сайта среди выданных адресов нет. Корзина ассистента остаётся отдельной до получения официального API корзины и способа привязки к сессии пользователя.

## Данные

В рабочем режиме агент получает актуальные товары через API каталога ekt.kz. Для разработки и защиты предусмотрен синтетический каталог с теми же полями: артикул, название, категория, характеристики, сертификаты, цена, остаток и доступность.

Цены и остатки берутся только из выбранного каталога. Ассистент не принимает платёжные данные и не изменяет корзину без явного подтверждения пользователя. В опубликованном демо корзина хранится в подписанном токене и доступна по кнопке; она не синхронизирована с ekt.kz и не оформляет заказ. Без `CART_SIGNING_KEY` локальный сервер использует прежнее хранение корзины в памяти процесса и не предоставляет ссылку на неё.

## Проверка пяти сценариев

В интерфейсе нажмите **«Пример диалога»** и последовательно отправьте вопросы:

1. **Наличие:** «Есть автомат на 25 А?»
2. **Аналог:** «DEMO-AV-25 нет в наличии? Какой аналог посоветуете?»
3. **Условия:** «Как у вас с оплатой и доставкой по Алматы? Есть минимальная партия?»
4. **Подтверждение:** «Да, добавь 2 шт DEMO-AV-16 в корзину».
5. **Корзина:** «Покажи корзину и дай ссылку».

Ожидаемый результат: ассистент отвечает по каталогу, предлагает доступную замену, объясняет условия, добавляет товар только после подтверждения и возвращает ссылку на демонстрационную корзину.

Негативные проверки: вопрос о цене не меняет корзину; количество выше остатка отклоняется; неизвестные товары, цены и наличие не выдумываются; платёжные данные не принимаются и не передаются модели.

## API и тесты

`POST /api/chat` принимает `{session_id, messages[], cart_token?}` и возвращает `{reply, cart, cart_link, cart_token, assistant_source, actions}`. `actions` содержит до шести кнопок с типом, подписью и командой на языке ответа; для `add_to_cart` сервер также задаёт артикул и максимальное доступное количество. Модель выбирает намерения через внутренний `set_ui_actions`, а сервер проверяет факты каталога и формирует подписи и команды. В демо-режиме выбор детерминированный. Кнопка добавления раскрывает выбор количества и меняет корзину только после подтверждения через обычный запрос чата. `cart_link` отсутствует, если открывать пока нечего. `assistant_source` показывает, ответила модель OpenAI, демо-сценарий или системная проверка. `GET /api/demo-questions` отдаёт вопросы из `logic/demo_questions.json` для синтетических данных либо примеры из загруженного живого каталога. `GET /health` сообщает источник каталога, а `GET /demo-cart?token=...` открывает подписанный снимок корзины ассистента.
