# EKT AI — ассистент интернет-магазина

EKT AI помогает клиентам ekt.kz подобрать электротехнический товар, узнать наличие и цену, найти аналог и собрать корзину без ожидания менеджера.

## Архитектура

```text
Веб-интерфейс → POST /api/chat → FastAPI → LLM-агент → каталог ekt.kz
                                      ↓
                              корзина и ссылка на ekt.kz
```

Фронтенд хранит историю диалога в открытой вкладке, а `session_id` — в `sessionStorage`. Если API недоступен, интерфейс сообщает об ошибке и не подменяет ответ вымышленными товарами или корзиной.

## Технологии

- FastAPI и Pydantic;
- OpenAI API с вызовом инструментов;
- HTML, JavaScript и Tailwind CSS CDN;
- API каталога ekt.kz или синтетический каталог при `DEMO_MODE=1`.

## Запуск

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Настройте переменные окружения:

   ```env
   OPENAI_API_KEY=...
   MODEL_NAME=gpt-4.1-mini
   DEMO_MODE=1
   ```

   Для живого каталога установите `DEMO_MODE=0`, `EKT_API_USER`, `EKT_API_PASSWORD` и при необходимости `CATALOG_PAGES`. `CORS_ORIGINS` задаёт разрешённые источники через запятую.

3. Запустите приложение:

   ```bash
   uvicorn main:app --reload
   ```

4. Откройте `http://127.0.0.1:8000`.

## Данные

В рабочем режиме агент получает актуальные товары через API каталога ekt.kz. Для разработки и защиты предусмотрен синтетический каталог с теми же полями: артикул, название, категория, характеристики, сертификаты, цена, остаток и доступность.

Цены и остатки берутся только из выбранного каталога. Ассистент не принимает платёжные данные и не изменяет корзину без явного подтверждения пользователя. Корзина прототипа хранится в памяти процесса и не синхронизируется с реальной корзиной ekt.kz; ссылка открывает страницу, где пользователь продолжает оформление самостоятельно.

## Проверка пяти сценариев

В интерфейсе нажмите **«Пример диалога»** и последовательно отправьте вопросы:

1. **Наличие:** «Есть автомат на 25 А?»
2. **Аналог:** «DEMO-AV-25 нет в наличии? Какой аналог посоветуете?»
3. **Условия:** «Как у вас с оплатой и доставкой по Алматы? Есть минимальная партия?»
4. **Подтверждение:** «Да, добавь 2 шт DEMO-AV-16 в корзину».
5. **Корзина:** «Покажи корзину и дай ссылку».

Ожидаемый результат: ассистент отвечает по каталогу, предлагает доступную замену, объясняет условия, добавляет товар только после подтверждения и возвращает ссылку на корзину ekt.kz.

Негативные проверки: вопрос о цене не меняет корзину; количество выше остатка отклоняется; неизвестные товары, цены и наличие не выдумываются; платёжные данные не принимаются и не передаются модели.

## API и тесты

`POST /api/chat` принимает `{session_id, messages[]}` и возвращает `{reply, cart, cart_link}`. `GET /api/demo-questions` отдаёт актуальные вопросы из `logic/demo_questions.json`.

```bash
python -m unittest discover -s tests -v
```
