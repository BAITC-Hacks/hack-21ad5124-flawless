# EKT AI — ассистент интернет-магазина

EKT AI помогает клиентам ekt.kz подобрать электротехнический товар, узнать наличие и цену, найти аналог и собрать корзину без ожидания менеджера.

## Архитектура

```text
Веб-интерфейс → POST /api/chat → FastAPI → агент → каталог EKT или демо-каталог
                                      ↓
                   корзина в панели чата → ссылка https://ekt.kz/cart
```

Фронтенд хранит историю диалога в открытой вкладке и `session_id` в `sessionStorage`. Сервер хранит корзины в памяти по `session_id`. Если внешний API недоступен, интерфейс сообщает об ошибке и не подменяет ответ вымышленными товарами, ценами или остатками.

## Технологии

- FastAPI и Pydantic;
- OpenAI API с вызовом инструментов;
- HTML, JavaScript и Tailwind CSS CDN;
- API каталога ekt.kz или синтетический каталог при `DEMO_MODE=1`.

## Запуск

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Настройте переменные окружения:

   ```env
   OPENAI_API_KEY=...
   MODEL_NAME=gpt-4.1-mini
   DEMO_MODE=1
   ```

   `DEMO_MODE=1` запускается без доступа к каталогу EKT. Без `OPENAI_API_KEY` используется детерминированный демо-агент, поэтому эксперты могут проверить обязательный сценарий без личных аккаунтов. Для живого каталога установите `DEMO_MODE=0`, выданные организаторами `EKT_API_USER` и `EKT_API_PASSWORD`; `CATALOG_PAGES` ограничивает число страниц при необходимости. `CORS_ORIGINS` задаёт разрешённые источники через запятую.

3. Запустите приложение:

   ```bash
   uvicorn main:app --reload
   ```

4. Откройте `http://127.0.0.1:8000`.

Публичное демо без авторизации: https://ekt-ai-assistant-demo.vercel.app. Режим и число загруженных товаров видны на `/health`; перед защитой публичный адрес нужно повторно проверить после деплоя интеграционной ветки.

### Деплой

Проект — обычный Python 3.12/FastAPI-сервис и не привязан к личной платформенной учётной записи. Для Render готов `render.yaml`; тот же `buildCommand`/`startCommand` можно использовать на Railway или сервере организаторов. Секреты задаются только защищёнными переменными окружения площадки и не хранятся в Git. Сама публичная ссылка и локальный `DEMO_MODE=1` не требуют от проверяющего входа в аккаунт владельца.

Для реального каталога нужны выданные организаторами `EKT_API_USER`, `EKT_API_PASSWORD` и `DEMO_MODE=0`. API EKT используется напрямую для чтения списка и деталей товаров; Pinecone и другие внешние векторные базы не требуются. Методов изменения реальной корзины сайта среди выданных адресов нет, поэтому панель корзины ассистента остаётся отдельной до появления официального API корзины.

## Данные

В рабочем режиме агент получает актуальные товары напрямую через API каталога ekt.kz. Для разработки и проверки без внешних аккаунтов предусмотрен синтетический каталог из 40 позиций по основным категориям с теми же полями: артикул, название, категория, характеристики, сертификаты, цена, остаток и доступность.

Цены и остатки берутся только из выбранного каталога. Ассистент не принимает платёжные данные и не изменяет корзину без явного подтверждения пользователя. Корзина ассистента хранится в памяти процесса, отображается в отдельной панели и не синхронизируется с реальной корзиной ekt.kz; `cart_link` ведёт на страницу корзины EKT для продолжения оформления.

## Проверка пяти сценариев

В интерфейсе нажмите **«Пример диалога»** и последовательно отправьте вопросы:

1. **Наличие:** «Есть автомат на 25 А?»
2. **Аналог:** «DEMO-AV-25 нет в наличии? Какой аналог посоветуете?»
3. **Условия:** «Как у вас с оплатой и доставкой по Алматы? Есть минимальная партия?»
4. **Подтверждение:** «Да, добавь 2 шт DEMO-AV-16 в корзину».
5. **Корзина:** «Покажи корзину и дай ссылку».

Ожидаемый результат: ассистент отвечает по каталогу, предлагает доступную замену, объясняет условия, добавляет товар только после подтверждения и возвращает `https://ekt.kz/cart`.

Негативные проверки: вопрос о цене не меняет корзину; количество выше остатка отклоняется; неизвестные товары, цены и наличие не выдумываются; платёжные данные не принимаются и не передаются модели.

## API и тесты

`POST /api/chat` принимает `{session_id, messages[]}` и возвращает `{reply, cart, cart_link}` — этот командный контракт не расширяется. `GET /api/demo-questions` отдаёт вопросы из `logic/demo_questions.json` для демо-каталога либо примеры из загруженного живого каталога. `GET /health` сообщает источник каталога и число товаров.

```bash
python -m unittest discover -s tests -v
```
